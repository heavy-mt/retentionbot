# Автоудаление сообщений Matrix — проект ТЗ, серверная версия

## Результат

Новые сообщения автоматически удаляются из переписки Element X по настроенному сроку.
В личных чатах остаются их обычные участники. Добавление бота и передача ему ключей
зашифрованной переписки не требуются.

Сервер заранее создаёт стандартное событие удаления. Клиент получает его при
синхронизации и применяет удаление к сообщению. Действующая серверная политика
retention продолжает очищать историю на сервере.

## Область работы

Все обслуживаемые комнаты Matrix, включая личные и зашифрованные чаты.
Учёт новых сообщений начинается после запуска службы. История до начала учёта
службой не обрабатывается. При изменении штатного retention сервер очищает историю
по своим действующим правилам.

Для сообщений пользователей своего сервера удаление выполняется от имени автора
либо подходящего существующего участника с правами удаления. Работа с сообщениями
пользователей чужих серверов зависит от наличия таких прав у локального участника.

## Управление

Администратор комнаты задаёт минимальный и максимальный срок через JSON API/CLI.
Вход выполняется с его обычной учётной записью Matrix. Права проверяются сервером
при каждой команде. Доступны настройка срока, просмотр состояния, справка и отключение,
если глобальная политика сервера допускает отключение.

Значения должны соответствовать серверным ограничениям. По умолчанию уведомление
об удалении создаётся за пять минут до максимального срока, с соблюдением минимального.
Сокращение максимального срока на этот запас должно быть согласовано для пилота.
Равные min/max при положительном запасе отклоняются.

Команды в зашифрованной переписке не являются интерфейсом управления этой версией.
Отдельный графический интерфейс в объём версии 0.2 не входит.

## Надёжность и наблюдение

Задания и сроки сохраняются после перезапуска. Повторная доставка задания не создаёт
повторное удаление. Актуальная политика проверяется непосредственно перед действием.
Ошибки, ожидание прав и пропуск после серверной очистки отражаются в статусе.

Команды, ответы и прикладные логи используют понятный JSON. Каждая запись лога
размещается на одной строке. Содержимое переписки и секреты в журналы не записываются.

Поставка включает Docker-образ модуля для проверенной версии Synapse и Compose
службы, очереди и БД. Брокер доступен только обработчикам службы.
Нагрузка более 100 сообщений/с проверяется отдельно на инфраструктуре заказчика.

## Файлы и ограничения

Историю сообщений физически очищает штатный retention Synapse. Файлы и миниатюры
очищаются отдельной штатной политикой хранения медиа — по времени последнего обращения.
Срок файлов может отличаться от срока сообщений. Удаление вложений E2EE точно по сроку
сообщения потребует отдельной интеграции и в эту версию не входит.

Element X может оставлять отметку об удалении. Долгий офлайн телефона до серверного
purge может помешать получению уведомления. Удаление скачанных копий, кэша и резервных
копий устройства не гарантируется серверной службой.

## Приёмка

Проверить обычный и зашифрованный личный чат на Element X Android/iOS: сроки,
получение удаления без перелогина, сохранение состава участников. Проверить управление
правами, перезапуски, повторные задания, сохранение штатного retention и доступность
очереди только обработчикам. Отдельно согласовать поведение при длительном офлайне
и сроки очистки файлов. Подробный перечень — в acceptance.md.
