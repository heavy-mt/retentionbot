# Автоудаление сообщений Matrix / Element X

Черновик рамок решения для согласования. Реализуемая версия: 0.1.0.

## Цель

Через заданный срок содержимое новых сообщений становится недоступным в Element X после
синхронизации с сервером, без выхода из учётной записи и повторного входа. Вложения,
размещённые на управляемом сервере Synapse, физически удаляются с сервера, когда они больше
не нужны другим учтённым сообщениям.

## Область работы

- Бот подключается ко всем обычным комнатам сервера, включая приватные и личные переписки,
  при наличии необходимых прав. Проблемы подключения видны администратору сервера.
- Каждая комната имеет свой срок: час, сутки, семь суток, тридцать суток либо отключение.
  Начальный срок — семь суток; его можно изменить до запуска.
- Настройками управляет администратор комнаты через команды в чате.
- Учитываются сообщения, отправленные после подключения бота к комнате. Старую историю
  задним числом не обрабатываем.
- Обрабатываются текст, вложения, редакции и реакции, в том числе в зашифрованных комнатах.
- Перезапуск службы сохраняет настройки и ожидающие задания. После временной недоступности
  сервера обработка возобновляется автоматически.
- Изменение срока применяется к учтённым сообщениям, которые ещё существуют. Восстановления
  уже удалённых сообщений нет.

## Как выглядит удаление

Используется штатное удаление Matrix. Предпочтительно полное исчезновение сообщения из ленты;
отметка «сообщение удалено» допустима, если её показывает Element X. Изменение приложения
Element X в эту поставку не входит.

Удаление выполняется по возможности вскоре после истечения срока. При выключенном телефоне
результат становится виден после подключения и синхронизации. Фактическое поведение, включая
долгий офлайн и неоткрытые комнаты, проверяется отдельно на Element X Android и iOS.

## Условия запуска

Нужен доступ к управляемому серверу Synapse и возможность создать служебную учётную запись.
Бот получает сообщения и ключи шифрования как участник комнат. Тексты сообщений и ключи
вложений в очереди заданий не сохраняются.

В этой версии сроком управляет бот. Штатное автоудаление Synapse отключается после подготовки
и проверки охвата комнат; старые серверные настройки сроков автоматически не переносятся.
Условия переключения согласуются до запуска на рабочем сервере.

## Ограничения физического удаления

Удаляются локальные вложения управляемого Synapse, загруженные после первого запуска службы.
Более старые файлы сохраняются, поскольку на них может ссылаться неучтённая история. Общие
файлы сохраняются до удаления последней учтённой ссылки. Аватары и защищённые файлы сохраняются.

Удаление копий на телефонах, в резервных копиях, на чужих серверах и во внешнем хранилище
вложений в эту версию не входит. Удаление содержимого сообщения не означает удаления всей
служебной информации Matrix об этом событии.

## Приёмка

На тестовом сервере проверяются права команд, разные сроки комнат, сохранение старой истории,
зашифрованные сообщения, удаление вложений, повторная доставка задания и перезапуски.
На телефонах проверяется исчезновение содержимого без перелогина, включая возвращение
после долгого офлайна. Подробные сценарии: [acceptance.md](acceptance.md).

Срок внедрения на рабочий сервер подтверждается после проверки доступа, состава комнат,
хранилища вложений и результатов клиентской приёмки.
